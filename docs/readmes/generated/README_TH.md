## OyasumiVR คืออะไร?

OyasumiVR เป็นแอปพลิเคชันบน Desktop ที่รวมเครื่องมือและระบบอัตโนมัติต่างๆ เพื่อ **ช่วยให้คุณนอนหลับในขณะที่สวมแว่น VR ได้อย่างราบรื่น** โดยฟีเจอร์ส่วนใหญ่ถูกสร้างมาเพื่อเน้นการใช้งานบนแพลตฟอร์มโซเชียล VR อย่าง [VRChat](https://vrchat.com)

OyasumiVR สามารถ **ตรวจจับได้ว่าคุณหลับเมื่อไหร่** และช่วยคุณในด้านต่างๆ เช่น:
- 🔋 ประหยัดไฟฟ้าและแบตเตอรี่ในระหว่างคืน
- 🔅 หรี่ความสว่างของหน้าจอแว่น VR
- ✨ สั่งการแอนิเมชันของ Avatar ตามท่าทางการนอนของคุณ
- 📩 จัดการคำขอเข้าร่วม (Invite Requests) โดยอัตโนมัติ
- 🔵 เปลี่ยนสถานะใน VRChat อัตโนมัติ
- 🎤 ปิดไมโครโฟนเมื่อคุณหลับ
- 🛠️ ตั้งค่าระบบต่างๆ ของ SteamVR โดยอัตโนมัติ

...และอีกมากมาย! โปรดอ่านเพิ่มเติมในส่วน "ฟีเจอร์" เพื่อดูรายละเอียดความสามารถทั้งหมดของ OyasumiVR

## สนับสนุน OyasumiVR

ตัวโปรแกรม OyasumiVR นั้นฟรี 100% และจะเป็นแบบนี้ตลอดไป อย่างไรก็ตาม หากคุณต้องการสนับสนุนผมและพัฒนาโปรแกรมนี้ คุณสามารถทำได้ผ่านช่องทางเหล่านี้:

<a href="https://patreon.com/Raphii"><img alt="Patreon Page" src="https://github.com/Raphiiko/OyasumiVR/assets/111654848/7d3d83a5-0900-4ccc-a514-ed1d616cb2ce"/></a>

การสนับสนุนของคุณจะช่วยให้เรามีเวลามากขึ้นในการพัฒนาฟีเจอร์ใหม่ๆ, ปรับปรุงระบบที่มีอยู่, ช่วยแบ่งเบาค่าใช้จ่ายในกระบวนการพัฒนา และช่วยเติมพลังกาแฟให้พวกเราด้วยครับ ☕

พวกเรายังไม่หยุดพัฒนา OyasumiVR แค่นี้แน่นอนและยังมีอีกหลายอย่างที่ **อยากจะทำเพิ่มครับ!**

## ฮาร์ดแวร์ที่รองรับ

### ระบบแบตเตอรี่อัตโนมัติ

ปัจจุบัน OyasumiVR รองรับการสั่งปิดอุปกรณ์ผ่านระบบแบตเตอรี่อัตโนมัติ สำหรับอุปกรณ์ SteamVR ทุกตัวที่:

1. รองรับการรายงานระดับแบตเตอรี่และสถานะการชาร์จ
2. รองรับการสั่งปิดผ่าน SteamVR

ซึ่งรวมถึง (แต่ไม่จำกัดเพียง) อุปกรณ์เหล่านี้:

- HTC Vive Controllers/Wands
- Index Controllers/Knuckles
- Vive Trackers (1.0/2.0/3.0)
- Tundra Trackers\*

นั่นหมายความว่า คอนโทรลเลอร์ของ Oculus มักจะใช้งานไม่ได้ และ SlimeVR ยังไม่รองรับ จนกว่าจะมีการเพิ่มฟีเจอร์นี้ลงใน [OpenVR driver](https://github.com/SlimeVR/SlimeVR-OpenVR-Driver) ของพวกเขา

_(\*) หมายเหตุ: Tundra Trackers มีการรายงานสถานะแบตเตอรี่ที่ล่าช้ามาก ระบบอัตโนมัติจะยังทำงานได้แต่จะล่าช้าไปหลายนาที (หลักสิบนาที) จนกว่าทาง Tundra จะแก้ไขใน Firmware_

### ระบบ GPU อัตโนมัติ

การควบคุมผ่านโปรไฟล์ MSI Afterburner รองรับการ์ดจอ NVIDIA หรือ AMD ทุกรุ่นที่โปรแกรม MSI Afterburner รองรับ

การควบคุมขีดจำกัดพลังงาน (Power Limit) โดยตรงผ่าน OyasumiVR รองรับเฉพาะการ์ดจอ NVIDIA เท่านั้น ผู้ใช้ AMD จำเป็นต้องตั้งโปรไฟล์ใน MSI Afterburner เพื่อให้ OyasumiVR เรียกใช้แทน

### ระบบความสว่างอัตโนมัติ

การควบคุมความสว่างในระดับฮาร์ดแวร์ ปัจจุบันรองรับเฉพาะ Valve Index และ Bigscreen Beyond

ส่วนการควบคุมความสว่างในระดับภาพ (Software Image Brightness) สามารถใช้งานได้กับแว่น VR ทุกรุ่น

### ระบบอุณหภูมิสีอัตโนมัติ

รองรับเฉพาะแว่น VR ที่เชื่อมต่อกับ SteamVR โดยตรงบางรุ่น เช่น Valve Index, Bigscreen Beyond และ HTC Vive (Pro) สำหรับรุ่นอื่นอาจใช้งานได้แต่ผลลัพธ์อาจแตกต่างกันไป

## VRChat

ฟีเจอร์บางอย่างของ OyasumiVR จำเป็นต้องให้คุณล็อกอินด้วยบัญชี VRChat (เช่น ระบบเปลี่ยนสถานะอัตโนมัติ)

ข้อมูลการล็อกอินของคุณจะถูกเก็บไว้ **เฉพาะในเครื่องของคุณเท่านั้น** และจะถูกส่งไปยังเซิร์ฟเวอร์ของ VRChat เพื่อการยืนยันตัวตนเท่านั้น

OyasumiVR ไม่ได้รับการรับรองจาก VRChat และไม่ได้สะท้อนถึงมุมมองหรือความคิดเห็นของ VRChat หรือใครก็ตามที่เกี่ยวข้องอย่างเป็นทางการในการผลิตหรือจัดการ VRChat เครื่องหมายการค้า VRChat เป็นของ VRChat inc. VRChat © VRChat Inc.

ผู้พัฒนาและผู้ร่วมสนับสนุนโครงการนี้จะไม่รับผิดชอบต่อปัญหาใดๆ ที่เกิดจากการใช้ OyasumiVR (ไม่ว่าจะเป็นกับบัญชี VRChat หรือด้านอื่นๆ) โปรดใช้งานด้วยความเสี่ยงของตัวท่านเอง

## Aptabase

OyasumiVR ใช้ระบบ Telemetry ของ [Aptabase](https://aptabase.com) ซึ่งเน้นความเป็นส่วนตัวและเปิดเผยซอร์สโค้ด เราใช้เพื่อเก็บรายงานการแครชและสถิติการใช้งานแบบไม่ระบุตัวตน เพื่อช่วยในการพัฒนาและแก้ไขบั๊ก

ข้อมูลนี้ไม่สามารถระบุตัวตนของคุณได้ และคุณสามารถเลือกปิด (Opt-out) การส่งข้อมูลนี้ได้ในการตั้งค่าทั่วไป สำหรับข้อมูลเพิ่มเติม (ทางเทคนิค) สามารถดูได้ที่ [Aptabase Privacy Policy](https://aptabase.com/legal/privacy)
