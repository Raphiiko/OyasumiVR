# Glossary

## Debug report

A zip of logs, settings with secrets removed, and system, SteamVR, and app state. A user creates
one on Raphii's request, to save as a file or to upload. Not "diagnostics package" or "issue
report".

## Report code

The short code a user gets after uploading a debug report. The user passes it to Raphii, who
fetches the report with it.
