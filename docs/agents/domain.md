# Domain documentation

All paths are relative to the repository root.

- Glossary: `docs/agents/CONTEXT.md`
- ADR directory: `docs/agents/adr/`
- ADR naming convention: `NNNN-short-title.md`, starting at `0001`

Before planning or changing a domain, read its relevant glossary entries and ADRs.
Record only agreed terminology and durable decisions in these documents.
Tickets hold task status, acceptance bookkeeping, and internal links.

Create the glossary and ADR files when there is agreed content to record.
Until then, these paths are reserved; do not create empty documents.
